Character Map — Phoenician-Order, Balanced Ternary Field

0 = SPACE — active vacuum, center of the ternary field
+1 → +26 = A–Z (uppercase, Phoenician order)
+27 → +36 = 0–9 (digits follow the alphabet)
−1 → −26 = a–z (lowercase, mirrored negative range)
−27 → −40 = Punctuation: - , . / : ; ! ? ( ) ' " @ #
Each character encodes to exactly 4 trits (3⁴ = 81 states, range −40 to +40).
Base-81: 4-trit groups, offset +40 → 1 digit/char LOSSLESS
Base-27: 6-trit groups (zero-extended), offset +13 → 2 digits/char LOSSLESS
Base-60: 4-trit groups, offset +30 mod 60 → 1 digit/char MODULAR (wraps at ±30)
